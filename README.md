# Equity & Legal Solutions – Law Firm Website

A Next.js + Tailwind CSS recreation of the [Atorn](https://templates.hibootstrap.com/atorn/default/index.html) law firm layout, populated with content from [Equity & Legal Solutions](https://www.aspiredelhilawyers.com/index.html).

## Features

- **Layout**: Same structure as Atorn (top bar, header, hero slider, feature cards, about, services, why choose us, case study, CTA quote, contact, testimonials, attorneys, partners, blog, footer).
- **Content**: Equity & Legal Solutions branding, practice areas (Apostille, Criminal, ED, PMLA, EOW, Cyber Crime, CBI, Property, NDPS, Family, Matrimonial, Divorce), cyber crime expertise, team, testimonials, and contact details.
- **Stack**: Next.js 14 (App Router), TypeScript, Tailwind CSS.
- **Design**: Navy (`#0d2137`), primary red (`#c41e3a`), serif headings, responsive layout.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Project Structure

- `src/app/` – App Router (layout, page, globals.css)
- `src/components/` – TopBar, Header, Hero, FeatureCards, AboutUs, Services, CyberCrime, WhyChooseUs, CaseStudy, CTAQuote, Contact, Testimonials, Attorneys, Partners, Blog, Footer
